### 2.1 方向判定流程（替换现行「A 定方向」）

```
1. 市场层：算出 p_市场。此时结论 = 无倾向。
2. 假设层：列出本场命中的假设及状态。
     · 只有「已验证」假设可提出方向。
     · 已验证假设之间方向相反 → 抵消，回到无倾向。
3. 基本面层：满足明文触发条件（碾压级五要素 ≥3 项 / 极端动力差异 ≥3 项）可提出方向。
     · 与已验证假设方向相反 → 无倾向，报告写明冲突。
4. 无人提出方向 → 第 7 节各判定写「无倾向」。
```

### 2.2 两个新指标（取代 0~100 置信度）

**信号强度**（决定 p_最终 是否偏离 p_市场）

| 档 | 条件 | p_最终 |
|----|------|--------|
| 无 | 没有已验证假设、基本面未触发覆盖 | = p_市场 |
| 弱 | 仅基本面触发覆盖 | = p_市场（基本面只定方向，不加概率） |
| 中 | 1 条已验证假设 | 按该假设登记后的命中率做 log-odds 平移，w 按样本量取 0.2/0.35/0.5 |
| 强 | ≥2 条已验证假设同向，或 1 条 + 基本面覆盖同向 | 同上，取命中率较高的那条 |

**数据质量**（只决定凯利分数）：起始 100，按下表扣减。

| 扣分项 | 分值 | 来源 |
|--------|------|------|
| 已错过节点 | 0/2/4/6/8/10/12/13/14/15/16 | 现行步骤 6 基础表，原样搬入 |
| 临场缺失附加 | 即时 2、临场④ 3、临场③ 2、临场② 2、临场① 1，合计上限 10 | 现行步骤 6，原样搬入 |
| 最新快照距开球 | ≤3h 0；3~12h 5；12~24h 10；24~48h 15；>48h 20 | 现行步骤 7 时效表（区间取上限） |
| 同节点报价不同步 | 5 | 现行 10 节点定义末尾的警告 |
| 临场④变盘 ≥0.25 球 | 10 | 现行通用防错清单 |
| 基本面缺块 | 每缺一块 3（近况/交锋/赛程/积分榜/伤停），上限 15 | 新增 |

**凯利分数** `k = 基础 k × 质量系数`

| 信号强度 | 基础 k | | 数据质量 | 质量系数 |
|---------|--------|-|---------|---------|
| 无 | 1/8 | | ≥80 | 1.0 |
| 弱 | 1/8 | | 60~79 | 0.75 |
| 中 | 1/4 | | 40~59 | 0.5 |
| 强 | 1/2 | | <40 | 0（pass） |

盘型封顶（平手盘 ≤65、半球盘 ≤75、深盘/杯赛 ≤65~70 等）全部删除：它们描述的是赛果方差，
已经由赔率和 edge 进入凯利公式，不需要再扣一次。

### WP-0.8 候选赔率口径 + 探索注

**赔率口径（已定）**：候选表「赔率」列一律取**首要分析庄的即时节点报价**，缺则按该联赛备选庄顺序。
`CLAUDE.md` 步骤 7.5 第 1 条加一句：「赔率列取首要分析庄即时价，表下注明是哪一家、哪个快照时间；
不得取『多庄最高价』或『可见较优价』。」p_市场 仍用多庄平均去抽水。实际下注前按现有规则用 BCG 报价重算。

**探索注（为提高入池率、多收样本）**：校准归零 + 锐庄价之后，正 edge 会很少。增加一个与「价值注」分开的档：

| 档 | 触发 | 选哪个 | 注额 | 标记 |
|----|------|--------|------|------|
| 价值注 | 有 eligible 且 edge >0 的候选 | 现行逻辑（Jev 或 edge 最高） | 凯利，见 2.2 节 | `tier=value` |
| 探索注 | 没有正 edge，但有 eligible 候选 edge ≥ 探索下限 | edge 最高的那一个，每场最多 1 注 | 固定平注 | `tier=explore` |
| 空仓 | 以上都不满足，或数据质量 <40 | — | 0 | PASS |

默认参数（放 `bot/config.py`，可随时调）：

| 参数 | 默认 | 含义 |
|------|------|------|
| `EXPLORE_MODE` | `on` | 关掉即回到「无正 edge 就空仓」 |
| `EXPLORE_MIN_EDGE` | −0.03 | 只在价格接近公平时探索；调低则入池更多、成本更高 |
| `EXPLORE_STAKE` | 1.0 | 每注固定美元数 |
| `EXPLORE_DAILY_MAX` | 5 | 每日探索注上限，按报告生成日计数 |

需要明白的两点：

- 探索注的期望收益是负的，成本约等于「注额 × |edge|」。按默认值每注最多亏 3 美分期望，100 注约 1~3 美元。
- **假设的命中率统计不依赖是否下注**：登记表按「触发 + 赛果」计数，没下注的比赛同样计入。
  探索注多收到的是你自己的执行数据（BCG 实际成交价、与参考价的差），不是假设验证样本。

代码改动（`bot/typesafe_decisions.py`）：

  ≥ `EXPLORE_MIN_EDGE` 的一项，`source="explore"`，`stake=EXPLORE_STAKE`，不调用 Jev。

## 6. 阶段 3：假设触发条件代码化

前提：WP-0.1 的导出数据到位。

### WP-3.1 统一的机械定义（写入登记表表头，也写进代码）

| 概念 | 定义 |
|------|------|
| 基准庄 | 本场联赛的首要分析庄，缺则按备选顺序 |
| 主线 | 基准庄在该节点报价中，两侧去抽水概率最接近 50/50 的那条让球线 |
| 初盘 / 终盘 | 我方最早采到的节点 / 开球前最后一个节点 |
| 变盘 | 基准庄主线让球绝对值相邻节点变化 ≥0.25 |
| 时段 | 早期 ≥24h；中期 6~24h；临场 ≤6h；末端 ≤1.5h |
| 热门方 | 基准庄欧赔去抽水概率从初盘到终盘上升 ≥1.5 个百分点的一方；≥3 为大热 |
| 欧亚差 | 实际初盘让球 − 欧赔换算理论让球；≥+0.25 记「深于换算」，≤−0.25 记「浅于换算」 |
| 水位档 | 净水位 <0.80 超低、0.80~0.87 低、0.87~0.95 中、0.95~1.05 高、>1.05 超高 |
| 单向升水 | 主线不变的连续 ≥3 个节点里上盘净水位单调上升且累计 ≥0.10 |
| 同步 | 同一时段内欧赔概率变化与亚盘变盘方向一致 |

### WP-3.2 实现

- 新文件 `bot/market_facts.py`：输入某场 `odds_history` 行，输出上表全部事实（纯函数，无 LLM）。
- 新文件 `bot/hypotheses.py`：每条可机械判定的假设一个函数，输入事实、输出是否触发和预测。
  先做 13 条军规、四大规则、大小盘升降、欧亚同步升/降盘、阻上/给水/诱上三形态，约 35 条。
  含主观条件、无法机械判定的假设在登记表标「不可机械判定」，永远停在「假设」状态，除非改写触发条件。
- `analyzer._analyze_prompts`：把事实表和触发的假设注入提示词（和现在注入「进球分布模型」同样的方式），
  LLM 不再自己匹配军规，只负责解释和写报告。
- 新脚本 `scripts/backtest_hypotheses.py`：对导出库全量比赛算触发、配比分和终盘价、输出每条假设的命中率与 ROI。

### WP-3.3 候选表由代码生成

把第 8 节候选表的枚举、取价、去抽水、五态 edge 计算移到代码（`goals_model.py` 已有 `edge_from_states`、
`_devig_two`、`states_for_csv`），LLM 只填信号强度、数据质量和可疑报价排除。
这样 `CLAUDE.md` 步骤 7.5 里大段防算错的规则可以删除。此包独立于假设层，可与 WP-3.2 并行。

### WP-3.4 验收

## 7. 阶段 4：验证与升级

- 登记日期 = 阶段 2 上线日。之后的比赛才计入门槛。
- 每周或每新增 30 场跑一次 `scripts/build_hypothesis_stats.py`，更新登记表「登记后样本」和状态。
- 状态变更（升为已验证、判为已否决）由人工确认后提交，不自动生效。
- 全量历史回测（WP-3.2）的结果作为「登记前样本」写入，用来决定优先观察哪些假设，不用来升级。

按每月约 100 份报告估算：触发率 40% 的假设（如 H-M09）约 2.5 个月达到 100 场；触发率 10% 的约 10 个月。
全量历史回测如果显示某条假设在数百场上明显为负，可以提前判否决，不必等登记后样本。
