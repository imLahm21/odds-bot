# 基本面层读法与方向覆盖条件

> **触发条件**：基本面与盘口方向矛盾；基本面一边倒（疑似碾压级）；涉及战意/动力差异（保级、争冠、杯赛、德比）。

## A. 基本面与盘口的关系（记录，不分配权重）

> 原「权重分配基准表」（一致 40/60、矛盾 20/80、杯赛 15/85、碾压浅开 30/70）**已删除**：
> 新四层不按权重投票，基本面与盘口**分别读、并列记录**。基本面与盘口方向矛盾时如实写明，
> 未满足 B1 覆盖条件则基本面不提出方向。

**杯赛特殊性**（读法）：杯赛（尤其淘汰赛/半决赛）状态与联赛可以完全脱节；联赛连败 ≠ 杯赛连败（动力、轮换、战术不同）；主场杯赛半决赛/决赛的「杯赛 DNA」记录为基本面事实。

## B. 碾压级基本面判定（方向覆盖触发条件）

> 来源：AS Roma 2-0 Lazio（2026-05-17 意甲罗马德比）。临场④主水反升 + 即时回调，机械套用诱上变体推荐下盘，实际上盘赢球赢盘。

**B1：碾压级基本面五要素（满足 ≥ 3 项成立 → 基本面层可提出方向，信号强度至少为「弱」）**：

| 基本面要素 | 阈值 |
|-----------|------|
| 联赛积分差 | **≥ 15 分** |
| 客队近 3 场战绩 | **2 场+ 大败（净负 ≥ 2 球）** |
| 客队赛程压力 | **3~7 天内有 2 场+ 重要比赛（杯赛+联赛连战）** |
| 主队主场近况 | **近 3 个主场全胜 + 进 5 球+** |
| 历史交锋 | **近 5 场主队胜率 ≥ 60%（不含走盘）** |

碾压级成立时，临场④主水反升 ≤ 10 点不计入 H-V-B / H-V-C / H-V-E 的触发（解释：散户大量押上盘时庄家平衡赔付敞口）。
要件逐项写入第 7 节「四层判断」的基本面一栏，**数据缺失的要件不算满足**。

**B2：碾压级与诱上类假设的触发互斥**：

1. **基本面碾压（B1 ≥3 项）** → 基本面层提出碾压方方向；诱上类假设不触发
2. 基本面均衡 + 全程不变盘 + 给水 + 临场④协同压主胜 → 记 H-V-B（[feedback_lure_variants.md](feedback_lure_variants.md) B 节）
3. 基本面均衡 + 临场④升盘 + 主水反升 → 记 H-P-B2（[feedback_sync_pricing.md](feedback_sync_pricing.md) B 节）

**H-F-B3（假设层）：临场④主水反升幅度分级**：

| 反升幅度 | 性质 | 记录 |
|---------|------|------|
| ≤ 5 点 | 正常市场波动 | 不触发 |
| **6~10 点** | 风控调整或诱上 | 碾压级基本面 → 不触发；均衡基本面 → H-F-B3 触发（预测上盘不出） |
| 11~15 点 | 诱上嫌疑较高 | H-F-B3 触发 |
| ≥ 16 点 | 诱上 | H-F-B3 触发（不论基本面） |

**H-F-B4（假设层）：欧赔即时回调幅度分级**：

| 欧赔即时回调 | 碾压级基本面 | 均衡基本面 |
|---------------|-----------|-----------|
| 0.01~0.03 | 不触发 | H-F-B4 触发（弱档） |
| 0.04~0.07 | 不触发 | H-F-B4 触发 |
| ≥ 0.08 | H-F-B4 触发 | H-F-B4 触发 |

## C. 客队疲态系数与德比修正

**C1：疲态信号（记录为基本面事实，休息天数直接引用【事实表】）**：

| 疲态信号 | 记录 |
|---------|---------|
| 距上场重要比赛 ≤ 3 天 | 体能疲态 |
| 上场重要比赛失利（如杯决败北） | 心理疲态 |
| 近 2 场失球 ≥ 5 个（防线崩塌） | 防守崩塌 |
| 客场连战 | 旅途疲态 |

触发多项时在基本面一栏逐项列出（如 Lazio 三项「残血出战」）；疲态是 B1「客队赛程压力」要件的输入，原「战力扣减 15%/10%/20%」百分比已删除（无样本）。

**C2：同城德比读法**：

| 场景 | 记录 |
|------|------|
| 德比 + 双方实力接近 + 同积分区 | 记录「德比小比分惯性」（基本面事实；走盘概率以模型分布为准） |
| **德比 + 实力碾压（积分差 ≥ 15 分）+ 客队疲态** | 按 B1 判定是否碾压级 |

## D. 战意与动力

**D1：保级队主场动力**（来源：Newcastle 3-1 Brighton）。主队处于保级区（排名 15-18）且主场作战时，记录「保级战意 + 主场」为偏主的基本面事实；原权重百分比已删除。

**D2：冠军压力下客场作战 = 保平争胜，而非「必须赢球」**（来源：Bournemouth 1-1 Man City，2026-05-20 英超冠军争夺战）。客场全力进攻风险高（可能 0 分），保平争胜风险低（至少 1 分），冠军压力下理性选择是**降低风险**。不可将「必须拿分」等同「必须赢球」而推客胜。

**D3：碾压级必须满足「对手崩溃」条件**（来源：同上）。历史交锋碾压 + 战略压力仅是碾压级的 2 项条件；对手近况良好（如 6 场不败）= **未崩溃**，不构成碾压级基本面。

**D4：保级死战 vs 无欲无求 = 极端动力差异**（基本面层方向覆盖条件）。**唯一维护位置在 [feedback_csl_fundamentals.md](feedback_csl_fundamentals.md) E 节**（触发要件、适用范围以该节为准），此处仅作指针。

## 本主题检查项

- [ ] 基本面与盘口矛盾时，是否两者并列记录、未互相改写？
- [ ] 杯赛是否已独立于联赛状态评估？
- [ ] 碾压级判定是否逐项核对五要素并 ≥ 3 项？对手未崩溃（近况不败）不可算碾压；数据缺失的要件不算满足
- [ ] 碾压级成立时，诱上类假设（H-V-B/C/E）是否已按互斥不记命中？
- [ ] 临场④主水反升 / 欧赔即时回调是否按 H-F-B3 / H-F-B4 分级记录？
- [ ] 客队疲态信号（≤3 天重要比赛 / 上场失利 / 近 2 场失 5 球）是否已列出（引用事实表休息天数）？
- [ ] 冠军争夺战客场方：是否按「保平争胜」而非「必须赢球」读？
