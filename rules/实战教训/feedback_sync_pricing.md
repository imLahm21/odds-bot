# 欧亚同步升降盘定价研判

> **触发条件**：任一阶段出现盘口升降（升盘 / 降盘 / 先升后降）。；盘口档位不变但两端价格跨节点显著反向移动时，也视为“有效变盘”，纳入本主题的定价修正路由。；淘汰赛次回合中，热门方首回合落后或被零封且必须追分时，欧亚同步强化也应触发赛制追热边界验证，并联查首回合证据与进球分盘冲突。
> 本文件先定性「真实定价 or 定价修正 or 诱导」；变体排查再走
> [feedback_lure_variants.md](feedback_lure_variants.md)（诱盘形态）、[feedback_late_stage_shift.md](feedback_late_stage_shift.md)（临场末端异动）。

## A. 欧亚同步升盘 = 真实定价（非诱盘）

> 来源：Chelsea 1-0 Leeds（2026-04-26 足总杯半决赛）。将升盘（平半→半球）判定为"诱上"推荐下盘，实际上盘 1-0 赢球赢盘。

**H-P-A1：欧亚同步升盘 → 预测上盘**（「真实定价」解释）。触发条件（同时满足）：

- 欧赔主胜方向持续下降（如 2.12 → 2.05）
- 亚盘同步升盘（如平半 → 半球）
- 两个方向一致且在**早中期完成**（非临场突变）

满足时不记 H-M04（深于换算+不变盘）/ H-M05（临场升盘）命中——触发条件互斥。

**H-P-A2：升盘前凯利极低 → 预测上盘，升盘后凯利回升不消解触发（底色）**

- 升盘前主凯利持续 < 0.97（尤其 < 0.90）= 庄家初盘阶段就真实看好主队
- 升盘后凯利回升至 1.0+ 是盘口加深后的数学结果，不代表庄家态度反转
- 记录方式：升盘前触发即记命中，升盘后的凯利变化另行记录

**H-P-A3：反常识升盘 → 预测升盘方**（原称「最强信号」，**无样本**）。基本面明显不利（连败、状态崩溃）但庄家仍升盘时触发。原「基本面权重大幅下调、盘口信号权重上调」已删除——两层分别记录，不互相改权重。

## B. 真实定价的边界条件（防教条化）

> 来源：云南玉昆 1-2 浙江（2026-05-06 中超）。临场④升盘 + 欧赔同步下降，机械套用规则 A 推荐上盘，实际上盘输盘。

**H-P-B1：H-P-A1 的四项边界条件**（任一项落在右列 → 不触发 H-P-A1，改记 H-P-B1：预测上盘不出）：

| 验证项 | 真实定价 | 诱导操作 |
|--------|---------|---------|
| 升盘时机 | 早中期完成（中盘②或更早） | **临场③④（≤1.5h 内）才升盘** |
| 升盘后欧赔 | 继续同方向或稳定 | **即时节点出现欧赔回调**（主胜回升/客胜回调） |
| 升盘后主水 | 适度调整（±5 点内）或下降 | **主水大幅反升 ≥ 10 点** |
| 升盘幅度 | ≤ 0.25 球 | ≥ 0.25 球（在临场④） |

**H-P-B2：升盘 + 主水持续上升 → 预测下盘（升盘版「诱上」）**（与 [feedback_late_stage_shift.md](feedback_late_stage_shift.md) A 节「降盘+主水反升」互为镜像）：

- 升盘后主水变化 ≤ 5 点 = 正常修正
- 升盘后主水上升 6~10 点 = 中性观察
- **升盘后主水持续上升 ≥ 10 点（含即时延续上升）= H-P-B2 触发**

**H-P-B3：升盘时机分档**（决定是否计入 H-P-A1）：

| 升盘时机 | 性质 | 触发判定 |
|---------|------|---------|
| 初盘②~中盘② | 定价基准修正 | 计入 H-P-A1 |
| 中盘③~临场① | 消息消化修正 | 计入 H-P-A1 |
| 临场②~③ | 资金调整 | 须主水方向 + 即时节点延续性同时满足才计入 |
| **临场④（≤30min）** | **知情资金窗口** | **须欧赔延续 / 主水方向 / 客胜凯利三项同时满足才计入** |

> 凯利侧配套：Pinnacle 客胜凯利 < 0.96 的优先级反转见 [feedback_kelly_signals.md](feedback_kelly_signals.md) D 节；
> 中超主场优势权重下调见 [feedback_csl_fundamentals.md](feedback_csl_fundamentals.md) F 节。

## C. 连续降盘 = 定价修正（H-M03 路径）

> 来源：浙江 2-1 深圳新鹏城（2026-05-02 中超）。初盘开大 + 临场连续降盘，误套军规 #4 推荐下盘，实际上盘赢球赢盘。

**C1（事实定义）：降盘 = 降低上盘赢盘门槛**：

| 操作 | 含义 | 对上盘影响 |
|------|------|-----------|
| 降盘（-0.75→-0.50→-0.25） | 降低让球深度 | **有利**（更容易赢盘） |
| 升盘（-0.50→-0.75→-1.0） | 加深让球深度 | **不利**（更难赢盘） |
| 不变盘 | 维持现有让球 | 需结合水位判断 |

**H-P-C2：深于换算 + 连续降盘 → 记 H-M03（修正→转场景三），不记 H-M04**：

| 场景 | 命中 |
|------|---------|
| 深于换算 + 不变盘 + 上盘大热 + 降水至低水 | H-M04（预测下盘胜） |
| 深于换算 + 早中期/临场降盘至合适 | **H-M03（修正→转场景三）** |
| 转场景三后 + 临场再降盘 | **H-M10（预测上盘赢球赢盘）** |

关键区分：H-M04 的触发条件是「不变盘」，一旦发生降盘即不满足。

**H-P-C3：欧赔主胜上升 + 亚盘降盘 → 预测上盘小胜（1 球）**。与 H-P-A1 互为镜像。

> 边界：临场③④剧烈降盘（欧主胜 > 0.50 或亚盘 ≥ 0.5 球）**不适用本节**，走 [feedback_late_stage_shift.md](feedback_late_stage_shift.md) B/C 节。

## D. 固定盘档下的有效降盘：多市场同步削弱

> 来源：法国 0-2 西班牙（2026-07-15 世界杯）。将 Pinnacle、Betfair 及多庄持续削弱法国误判为西班牙过热诱盘，反买法国。存档：20260715_case_12_France_vs_Spain.md。

**H-P-D1：固定盘口档位不等于稳态“不变盘”**。让球档位虽然维持法国 -0.25，但法国回报由 2.03 升至 2.21、西班牙 +0.25 由 1.88 降至 1.77，且变化跨越多个阶段，记为“有效降盘”。此时不满足 H-M09（真正不变盘）的触发条件。

**H-P-D2：首要锐庄 + 交易所 + 多数传统庄同向削弱一方 → 预测被削弱方不出**（「真实重新定价」解释）。热门方只是事实记录，不能把“热门方”自动等同于“诱盘方”。

**D3（读数规范）：单庄离散不计入多市场共识**。若只有一家传统庄给出明显低价或低凯利，而首要锐庄没有同步保护，记为跨庄离散（可能是定价体系、时差或返还率差异），不计入任何假设的触发条件。

**H-P-D4：降温方向的预测落在「不胜 / 受让盘」，不落在精确赛果**。本场盘口指向法国不胜、西班牙受让赢盘，但不区分平局与客胜。选哪个玩法仍只看第 8 节 edge。

与 C 的区别：C 是让球档位连续下降；D 是让球档位固定，但两端价格持续向下盘倾斜。两者都属于定价修正路径，但 D 必须由跨节点、多市场共振确认，不能把单次水位波动视为有效降盘。

## E. 淘汰赛次回合追分热：同步强化的赛制边界

> 来源：Hapoel Beer Sheva 1-0 FK Crvena Zvezda（2026-08-05 欧冠）。将同步降赔升盘视为真实定价并首选客胜、追大，忽略了次回合追分题材与零进球保护。存档：20260805_case_13_Hapoel_Beer_Sheva_vs_FK_Crvena_Zvezda.md。

**H-P-E1：淘汰赛次回合追分场景下 H-P-A1 不触发**。当热门方首回合落后、必须追分，欧赔下压与亚盘升盘可能同时包含实力修正、战意题材和追热资金。若又出现欧亚一致、持续升盘、上盘高度受热，改记 H-M11 / H-P-E1（预测下盘）。

**H-P-E2：热门方首回合被零封 + 领先方可控制节奏 → 预测受让盘与小球**。首回合证据在基本面层优先于普通 H2H 记录；不能把“必须进攻”推导为必胜或多进球。

**H-P-E3：热门方进球降赔与锐庄零进球保护并存 → 预测热门方进球少**。当热门方大1.5等进球盘口持续降赔，而首要锐庄对其小0.5给出极低凯利时触发；第 5 节记录为进球市场分歧。

**H-P-E4：H-M11 触发且首要锐庄热门胜赔凯利未低于 0.96 → 预测受让方直接取胜**。亚盘受让与胜平负必须分开记录，不能用胜赔持续下压替代锐庄确认。

与 A 的区别：A 处理一般场景下早中期完成的欧亚同步升盘；E 处理淘汰赛次回合“首回合落后或被零封＋必须追分＋热门拥挤”的姊妹场景，二者触发条件互斥。

## 本主题检查项

- [ ] 欧亚同步升盘且早中期完成？→ 记 H-P-A1；同时不记 H-M04 / H-M05
- [ ] 升盘前主凯利持续 < 0.97？→ 记 H-P-A2，升盘后回升不消解
- [ ] 升盘发生在临场④？→ 按 H-P-B3 三项条件判定是否计入 H-P-A1
- [ ] 升盘后主水持续反升 ≥ 10 点（含即时）？→ 记 H-P-B2
- [ ] 连续降盘是否误记 H-M04？（H-M04 触发条件是不变盘，降盘记 H-M03）
- [ ] 欧主胜升 + 亚盘降发生在早中期？→ 记 H-P-C3；临场末端剧烈异动除外
- [ ] 盘口档位未变但两端价格跨节点显著反向移动？→ 记有效变盘（H-P-D1），不记 H-M09
- [ ] Pinnacle、Betfair 与多数传统庄持续同向削弱一方？→ 记 H-P-D2；不因对手受热而推诱盘
- [ ] 仅单庄低价或低凯利与首要庄、多庄共识冲突？→ 记为跨庄离散，不计入触发
- [ ] 淘汰赛次回合热门方首回合落后且“必须赢”，又同步降赔升盘？→ 不记 H-P-A1，按 H-P-E1 / H-M11 记录
- [ ] 热门方进球降赔与锐庄其小0.5极低凯利并存？→ 记 H-P-E3，第 5 节写明进球市场分歧
