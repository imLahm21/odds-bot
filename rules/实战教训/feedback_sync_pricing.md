# 欧亚同步升降盘定价研判

> **触发条件**：任一阶段出现盘口升降（升盘 / 降盘 / 先升后降）。；盘口档位不变但两端价格跨节点显著反向移动时，也视为“有效变盘”，纳入本主题的定价修正路由。；淘汰赛次回合中，热门方首回合落后或被零封且必须追分时，欧亚同步强化也应触发赛制追热边界验证，并联查首回合证据与进球分盘冲突。
> 本文件先定性「真实定价 or 定价修正 or 诱导」；变体排查再走
> [feedback_lure_variants.md](feedback_lure_variants.md)（诱盘形态）、[feedback_late_stage_shift.md](feedback_late_stage_shift.md)（临场末端异动）。

## A. 欧亚同步升盘 = 真实定价（非诱盘）

> 来源：Chelsea 1-0 Leeds（2026-04-26 足总杯半决赛）。将升盘（平半→半球）判定为"诱上"推荐下盘，实际上盘 1-0 赢球赢盘。

**规则 A1：欧亚同步升盘 = 真实定价**。以下条件同时满足时，升盘必须视为庄家真实看好上盘：

- 欧赔主胜方向持续下降（如 2.12 → 2.05）
- 亚盘同步升盘（如平半 → 半球）
- 两个方向一致且在**早中期完成**（非临场突变）

此时不可套用军规 #4（开大+不变盘+诱上）或 #5（升盘诱上），升盘本身是定价修正。

**规则 A2：升盘前凯利极低信号不可被升盘后数据覆盖（底色信号）**

- 升盘前主凯利持续 < 0.97（尤其 < 0.90）= 庄家初盘阶段就真实看好主队
- 升盘后凯利回升至 1.0+ 是盘口加深后的数学结果，不代表庄家态度反转
- 正确做法：以升盘前的凯利趋势为「底色」，升盘后的凯利变化仅作微调参考

**规则 A3：反常识升盘 = 最强信号**。基本面明显不利（连败、状态崩溃）但庄家仍升盘时：庄家掌握超越公开信息的判断；越与基本面矛盾的盘口变动越可能含内幕信息。此时基本面权重大幅下调、盘口信号权重上调。

## B. 真实定价的边界条件（防教条化）

> 来源：云南玉昆 1-2 浙江（2026-05-06 中超）。临场④升盘 + 欧赔同步下降，机械套用规则 A 推荐上盘，实际上盘输盘。

**规则 B1：判定真实定价必须同时通过四项验证**：

| 验证项 | 真实定价 | 诱导操作 |
|--------|---------|---------|
| 升盘时机 | 早中期完成（中盘②或更早） | **临场③④（≤1.5h 内）才升盘** |
| 升盘后欧赔 | 继续同方向或稳定 | **即时节点出现欧赔回调**（主胜回升/客胜回调） |
| 升盘后主水 | 适度调整（±5 点内）或下降 | **主水大幅反升 ≥ 10 点** |
| 升盘幅度 | ≤ 0.25 球 | ≥ 0.25 球（在临场④） |

**规则 B2：升盘 + 主水持续上升 = 升盘版「诱上」**（与 [feedback_late_stage_shift.md](feedback_late_stage_shift.md) A 节「降盘+主水反升」互为镜像）：

- 升盘后主水变化 ≤ 5 点 = 正常修正
- 升盘后主水上升 6~10 点 = 中性观察
- **升盘后主水持续上升 ≥ 10 点（含即时延续上升）= 诱上信号**

**规则 B3：临场④升盘必须独立验证，不可直接套用早中期规则**：

| 升盘时机 | 性质 | 处理规则 |
|---------|------|---------|
| 初盘②~中盘② | 定价基准修正 | 直接套用「欧亚同步升盘=真实定价」 |
| 中盘③~临场① | 消息消化修正 | 套用真实定价，置信度扣减 5 |
| 临场②~③ | 资金调整 | 必须验证主水方向 + 即时节点延续性 |
| **临场④（≤30min）** | **知情资金窗口** | **必须三重验证（欧赔延续 / 主水方向 / 客胜凯利）** |

> 凯利侧配套：Pinnacle 客胜凯利 < 0.96 的优先级反转见 [feedback_kelly_signals.md](feedback_kelly_signals.md) D 节；
> 中超主场优势权重下调见 [feedback_csl_fundamentals.md](feedback_csl_fundamentals.md) F 节。

## C. 连续降盘 = 定价修正（军规 #3 路径）

> 来源：浙江 2-1 深圳新鹏城（2026-05-02 中超）。初盘开大 + 临场连续降盘，误套军规 #4 推荐下盘，实际上盘赢球赢盘。

**规则 C1：降盘 = 降低上盘赢盘门槛 = 对上盘有利**。若庄家真的不看好上盘，应升盘或维持：

| 操作 | 含义 | 对上盘影响 |
|------|------|-----------|
| 降盘（-0.75→-0.50→-0.25） | 降低让球深度 | **有利**（更容易赢盘） |
| 升盘（-0.50→-0.75→-1.0） | 加深让球深度 | **不利**（更难赢盘） |
| 不变盘 | 维持现有让球 | 需结合水位判断 |

**规则 C2：初盘开大 + 连续降盘 → 军规 #3（修正→转场景三），不是军规 #4**：

| 场景 | 正确匹配 |
|------|---------|
| 初盘开大 + 不变盘 + 上盘大热 + 降水至低水 | 军规 #4（诱上→下盘胜） |
| 初盘开大 + 早中期/临场降盘至合适 | **军规 #3（修正→转场景三）** |
| 转场景三后 + 临场再降盘 | **军规 #10（减小上盘赔付→上盘赢球赢盘）** |

关键区分：军规 #4 的前提是「不变盘」，一旦发生降盘走军规 #3 路径。

**规则 C3：欧赔主胜上升 + 亚盘降盘 = 同步定价修正（「上盘小胜」信号）**。欧赔放开主胜赔付 + 亚盘降低让球门槛 = 庄家认为上盘小胜（1 球）。与规则 A（同步升盘=真实定价）互为镜像。

> 边界：临场③④剧烈降盘（欧主胜 > 0.50 或亚盘 ≥ 0.5 球）**不适用本节**，走 [feedback_late_stage_shift.md](feedback_late_stage_shift.md) B/C 节。

## D. 固定盘档下的有效降盘：多市场同步削弱

> 来源：法国 0-2 西班牙（2026-07-15 世界杯）。将 Pinnacle、Betfair 及多庄持续削弱法国误判为西班牙过热诱盘，反买法国。存档：20260715_case_12_France_vs_Spain.md。

**规则 D1：固定盘口档位不等于稳态“不变盘”**。让球档位虽然维持法国 -0.25，但法国回报由 2.03 升至 2.21、西班牙 +0.25 由 1.88 降至 1.77，且变化跨越多个阶段，已构成显著的“有效降盘／重新定价”。此时不得套用以真正不变盘为前提的军规 #9。

**规则 D2：首要锐庄 + 交易所 + 多数传统庄同向，优先判为真实重新定价**。当 Pinnacle、Betfair 与多数公司连续削弱同一方时，应先接受市场胜率修正；识别出另一方受热只是第一步，不能把“热门方”自动等同于“诱盘方”。

**规则 D3：单庄离散不得推翻多市场共识**。若只有一家传统庄给出明显低价或低凯利，而首要锐庄没有同步保护，应将其视为定价体系、时差或返还率差异造成的离散信号，不能据此反向下注。

**规则 D4：真实降温信号先落到不胜与受让盘，不越级锁定精确赛果**。本场盘口较强地指向法国不胜、西班牙受让赢盘，但不足以高置信区分平局与客胜；实战优先选择西班牙 +0.25 或西班牙 0，而非直接重注客胜。

与 C 的区别：C 是让球档位连续下降；D 是让球档位固定，但两端价格持续向下盘倾斜。两者都属于定价修正路径，但 D 必须由跨节点、多市场共振确认，不能把单次水位波动视为有效降盘。

## E. 淘汰赛次回合追分热：同步强化的赛制边界

> 来源：Hapoel Beer Sheva 1-0 FK Crvena Zvezda（2026-08-05 欧冠）。将同步降赔升盘视为真实定价并首选客胜、追大，忽略了次回合追分题材与零进球保护。存档：20260805_case_13_Hapoel_Beer_Sheva_vs_FK_Crvena_Zvezda.md。

**规则 E1：淘汰赛次回合“必须赢”不是同步强化的真实定价确认**。当热门方首回合落后、必须追分，欧赔下压与亚盘升盘可能同时包含实力修正、战意题材和追热资金。若又出现初盘合适、持续升盘、上盘高度受热，不可直接套用 A1，必须按军规 #11 排查下盘。

**规则 E2：同轮首回合证据高于普通 H2H**。热门方首回合被零封，说明其破防能力已在相同阵容、教练和战术环境中受检验；领先方次回合又可压缩空间、控制节奏时，应同步提高受让盘与小球权重，不能把“必须进攻”推导为必胜或多进球。

**规则 E3：热门方进球降赔与锐庄零进球保护并存，属于严重冲突**。当热门方大1.5等进球盘口持续降赔，而首要锐庄对其小0.5给出极低凯利时，不得只跟随名义低赔方向；大小球置信度应降至 65 以下，优先回避追大。

**规则 E4：下盘成立不得收敛成“热门方小胜”单一路径**。亚盘受让与胜平负必须独立推演；出现军规 #11 过热，且首要锐庄热门胜赔凯利未低于 0.96 时，应给受让方直接取胜独立权重，不能用胜赔持续下压替代锐庄硬确认。

与 A 的区别：A 处理一般场景下早中期完成的欧亚同步升盘；E 处理淘汰赛次回合“首回合落后或被零封＋必须追分＋热门拥挤”的姊妹场景。E 并非将同步强化一概判为诱盘，而是要求结合首回合、凯利和进球分盘进行二次验证。

## 本主题检查项

- [ ] 欧亚同步升盘且早中期完成？→ 按真实定价处理，不套诱上军规（A1）
- [ ] 升盘前主凯利持续 < 0.97？→ 保留为底色信号，升盘后回升不代表反转（A2）
- [ ] 升盘发生在临场④？→ 不可直接套真实定价，执行 B3 三重验证
- [ ] 升盘后主水持续反升 ≥ 10 点（含即时）？→ 升盘版诱上（B2）
- [ ] 即时节点欧赔是否回调？→ 回调 = 信号方向反转（B1）
- [ ] 连续降盘是否误套军规 #4？（#4 前提是不变盘，降盘走 #3 路径）（C2）
- [ ] 欧主胜升 + 亚盘降发生在早中期？→ 上盘小胜；临场末端剧烈异动除外（C3）
- [ ] 盘口档位未变但两端价格跨节点显著反向移动？→ 视为有效变盘，不套真正不变盘的军规 #9
- [ ] Pinnacle、Betfair 与多数传统庄持续同向削弱一方？→ 优先按真实重新定价处理，不因对手受热而机械反买
- [ ] 仅单庄低价或低凯利与首要庄、多庄共识冲突？→ 降为离散信号，不得推翻市场共识
- [ ] 重新定价只明确不胜或受让赢盘，尚未区分平负？→ 选择受让盘或平手盘，不高置信锁定胜平负
- [ ] 淘汰赛次回合热门方首回合落后且“必须赢”，又同步降赔升盘？→ 不直接套 A1，拆分真实定价与追分热并按军规 #11 排查
- [ ] 同轮首回合热门方被零封、领先方可控制节奏？→ 提高受让与小球权重，压低热门方胜场和多进球判断
- [ ] 热门方进球降赔与锐庄其小0.5极低凯利并存？→ 判为进球市场严重冲突，将大小球置信度降至65以下并回避追大
- [ ] 下盘成立但热门胜赔持续下压、锐庄胜赔凯利未低于0.96？→ 亚盘与胜平负分开推演，保留受让方直接取胜路径
