# H2H 历史交锋读法

> **触发条件**：用户提供两队历史交锋（H2H）数据；或两队积分接近/排名相邻。

## A. H2H 高平局率（记录为基本面事实）

> 来源：霍芬海姆 3-3 斯图加特（2026-05-02 德甲）。近 5 次交锋 4 平（80%）。

**A1：平局率分档记录**（交锋场次与平局率直接引用【事实表】）：

| H2H 近 5~10 场平局率 | 记录 |
|---------------------|---------|
| < 40% | 不单独记录 |
| 40%~59% | 记录「交锋平局偏多」 |
| **≥ 60%**（5 场中 ≥ 3 平） | 记录为基本面事实；**不自动调整首选** |

> 原「≥60% → 平局并列首选、扣 5~10 分」「≥80% → 封顶 65」「盘口 50% / 平局率 50%、上限 70」**已删除**
> （2026-11 回测：首选平局 118 次，命中 28.8%）。平局概率以 p_市场 为准。
> 与平局凯利 < 0.96 同时出现时两者分别记录（[feedback_kelly_signals.md](feedback_kelly_signals.md) G 节），不叠加成方向。
> H2H 与本赛季近况冲突时，**本赛季 > 历史交锋**（见 B 节）。

**A3：同积分/同排名对手**：积分差 ≤ 3 分 + 排名相邻（差 ≤ 2 位）+ 均有明确赛季目标 → 记录为基本面事实（「势均力敌」）。

## B. H2H 与本赛季实力差的关系（分类记录）

> 来源：Chelsea 2-1 Tottenham（同向）、河南 0-2 浙江（接近）、上海海港 2-2 浙江（反向）。

**核心读法：H2H 与本赛季同向时历史优势可信；本赛季实力已追平或反向时历史优势被抵消**：

| 场景 | 记录 |
|------|------|
| H2H 主场不败率 ≥80% + 本赛季积分差**主队领先 ≥8 分** | 「H2H 与本赛季同向」——作为偏主的基本面事实 |
| H2H 主场不败率 ≥80% + 本赛季**积分差 ≤3 分** | 「H2H 优势被本赛季抵消」 |
| H2H 碾压 + 客队本赛季大胜强队 | 「H2H 优势被本赛季抵消」 |
| H2H 碾压 + 主场平局率 ≥30% | 「H2H 优势伴随高平」 |
| **H2H 占优方本赛季排名/积分反向** | 「H2H 与本赛季反向」——以本赛季为准 |

> 原权重表（35%/20%/30%/25%）与「置信度至少扣 10 分」已删除。

## C. 低迷期的 H2H

> 来源：浙江 2-1 深圳新鹏城。主队近况差 + H2H 占优时，记录「低迷期遇 H2H 占优对手」为基本面事实（「止颓」读法）。

## D. 联赛差异

> 原「中超 25% / 五大联赛 30% / 英超 35%」H2H 主场优势权重表已删除（无样本）；联赛主场优势差异由市场价格体现。

## E. 理论盘口应基于本赛季状态，而非历史交锋

> 来源：Bournemouth 1-1 Man City。基于 H2H 曼城 9 胜 1 负判理论盘口 1.0~1.25 球，误判"初盘开小"。

步骤 2 的理论盘口**只来自欧赔换算**（`reference_asian_handicap.md` 第十一章）；H2H 不参与理论盘口。

## 本主题检查项

- [ ] H2H 平局率是否引用事实表并按 A1 分档记录？≥60% 也不自动调整首选
- [ ] 积分差 ≤ 3 分且排名相邻？→ 记录「势均力敌」
- [ ] H2H 与本赛季是同向、被抵消还是反向？（B 节分类）
