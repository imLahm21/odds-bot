# 强队深盘 / 杯赛冷平

> **触发条件**：强队让 -1.5 及以上深盘；**或热门方始终浅让（-0.5）拒绝加深**；世界杯/洲际杯/杯赛强弱对话；热门方欧赔被压至 1.2x 以下且平赔 ≥ 7.0；**或多家公司客胜凯利偏低（冷门保护）**。
> A/B/C 为姊妹场景：同源于「热门胜场存疑」——上盘死，A 走向冷平（深盘）、B 走向受让方直接反胜（深盘降温）、C 走向受让方不败（浅让不升盘 + 客胜低凯利）。
> 国家队赛事基本面读法配套 `reference_national_team.md` 第四、六章。

## A. 强队深盘 + 高平赔的冷平风险

> 来源：England 0-0 Ghana（2026-06-24 世界杯小组赛）。欧赔压至 1.18~1.20 + 亚盘 -1.75 升 -2.0 且上盘水位压至均衡，判"升盘降赔真实强化"推上盘+主胜 3-0/3-1，实际 0-0 冷平，深盘全输。

**H-X-A1：强队「欧亚一致 + 升盘至深盘」→ 预测下盘（降赔式诱上）**。H-M11 的触发**不以**"升盘后主水大幅反升"为必要条件——强队深盘场景中即使升盘后上盘水位不升反降，也照记 H-M11 / H-X-A1 命中。

**H-X-A2：杯赛强弱盘，平赔 ≥ 7.0 → 预测冷平概率被低估**。平局概率以 p_市场 为准，不得在文字结论里写「排除平局」。

**H-X-A3：深盘主盘口（-1.75/-2.0）双方凯利接近 1.0 → 预测主胜不稳**（「市场对深盘无保护」解释）。

**H-X-A4：2.5 大球低水 + 3.5 小球低水并存 → 预测比分收敛**。比分仍按模型分布取最可能的两个；本条命中时在风险提示中写明 0-0、1-0、1-1 的模型概率。

> 原规则 A5（深盘/杯赛/缺终指/凯利分歧 ≥2 项封顶 65~70）**已删除**：盘型方差已由赔率与 edge 进入凯利公式；
> 缺基本面块由质量层扣分。个别公司平局凯利极低与主流 >1.03 并存，记为第 5 节跨庄分歧。

## B. 升盘至深盘后临场降温 = 受让方可能直接反胜

> 来源：Ecuador 2-1 Germany（2026-06-26 世界杯小组赛）。正确判出"Germany 穿 -1 不稳、亚盘看 Ecuador +1"（命中），但胜平负仍首选客胜 Germany → 亚盘对、胜平负全错。

**H-X-B1：亚盘方向 ≠ 胜平负方向**。亚盘与胜平负判定分开写；预测：杯赛环境下受让 +1 的赢盘常由受让方直接赢球兑现。

**H-X-B2：完整信号链 → 预测热门胜场动摇**：
欧亚一致 → 中盘剧烈升盘 → 临场上盘高水不降 → 热门胜赔回升 → 受让方赔率回压。

**H-X-B3：中盘剧烈欧亚同步加深，临场未延续 → 预测热门不出**（「制造强势题材」解释）。与 H-P-A1 触发条件互斥。

**H-X-B4：热门胜赔从低点回升 + 上盘高水 + 受让方赔率回压 → 预测热门不胜**。

**H-X-B5：受让方方向 + 热门胜赔明显回升 → 预测受让方取胜比分**（受让方 2:1 / 1:0）。

## C. 热门浅让不升盘 + 客胜低凯利（假设 H-X-C1~C3）

> 来源：Brazil 1-2 Norway（2026-07-06 World Cup）。亚盘正确判出 Norway +0.5，但胜平负仍首选主胜 Brazil、仅列平局次选 → 亚盘对、胜平负偏差（实际客胜）。存档：[20260706_case_06_brazil_vs_norway.md](20260706_case_06_brazil_vs_norway.md)。

**与 A/B 的区别**：A/B 是热门**升盘至深盘**（-1.5/-2.0）后翻车；C 是热门**始终浅让、拒绝加深**（-0.5 不升 -0.75）——同为"热方胜场存疑"，但盘型相反，识别信号也不同。深盘看"升盘后降温"，浅让看"该深不深 + 客胜被保护"。

**H-X-C1：热门浅让不升盘 → 预测热门不胜**。强队被市场认定热门，但庄家让球始终锁在浅盘（-0.5）、拒绝随热度加深至 -0.75 时触发。（原称「军规 #9 热方有难的国家队强化版」；H-M09 已改为无方向，本条独立登记。）

**H-X-C2（原「须改判为受让方不败优先」）：≥ 2 家公司客胜凯利明显偏低 → 预测受让方不败**（「冷门保护」解释）。只记录命中，不得据此改方向。

**H-X-C3：浅让不升盘 + 客胜低凯利 + 2.5 大球低水三者并存 → 预测受让方赢球**（而非 0-0）。

**C4（基本面层读法）：国家队赛事「名气 ≠ 实力锚」**。Brazil 名气远高于 Norway，但 Norway 当届正式赛（世预赛/欧国联）强度足以支撑不败/客胜。判热门胜场时须用当届实力锚（见 `reference_national_team.md` 第四章），不可只按传统名气定主胜。
