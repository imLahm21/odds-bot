# 中超基本面读法

> **触发条件**：中超（及状态波动类似的次级联赛）赛事必读。
> 底层逻辑：中超赛程密集（联赛+足协杯+亚冠）+ 体能管理差 → 状态波动大；主场胜率基准仅 38%~42%（五大联赛 45%~50%），主场优势与排名差的参考价值均低于欧洲联赛。

## A. 近况崩溃期的主场反弹规律

> 来源：浙江 2-1 深圳新鹏城（2026-05-02 中超）。两队近况均差误判"平局概率最高"，实际主队反弹取胜。

| 条件 | 判断 |
|------|------|
| 主队连续 3 场+ 不胜 + 客队客场连续 2 场+ 不胜 | 记录「主场反弹」读法：偏主 |
| 主队连续 3 场+ 不胜 + 客队客场状态正常 | 不记偏离 |
| 两队近况均崩溃 | 记录「主场反弹」读法：偏主 |

低迷期 H2H 读法见 [feedback_h2h_weight.md](feedback_h2h_weight.md) C 节；近况必须按对手质量量化（[feedback_home_away_quality.md](feedback_home_away_quality.md) C 节）。

## B. 中超主场反弹潜力四条件

> 来源：浙江 4-1 山东泰山（2026-05-20 中超）。过度放大客队状态优势，低估主队主场交锋能力。存档：[20260520_case_01_zhejiang_vs_shandong.md](20260520_case_01_zhejiang_vs_shandong.md)。

四项同时满足 → 记录「主场反弹潜力」，作为偏主的基本面事实：

| 条件 | 阈值 |
|------|------|
| ① 主队历史主场交锋不败率 | ≥ 60%（近 5 场） |
| ② 客队近 10 场客场大败前科 | 存在净负 ≥ 3 球记录 |
| ③ 主队近况输球对手质量高 | 输给联赛前 3 强队 |
| ④ 积分差 | ≤ 10 分 |

> 原权重修正（25%→10%、15%→35% 等）与「置信度上限 80」已删除。
> **边界**：本赛季积分差 ≤ 3 分时按 [feedback_h2h_weight.md](feedback_h2h_weight.md) B 节记为「H2H 优势被本赛季抵消」。

## C. 中超单场大败 ≠ 持续崩溃

> 来源：河南 0-2 浙江（2026-05-30 中超）。浙江 0-5 惨败 6 天后被判"真实崩溃"，实际客场 0-2 完胜。

判定崩溃前逐项验证：

| 验证项 | 非崩溃 | 真实崩溃 |
|--------|------------------------|----------------------|
| 大败后是否有大胜记录 | 有（0-5 后 4-1 胜强队）= 波动大 | 无，连续 3 场大败 |
| 大败对手是否强队 | 是（前 3 名）= 输强队 | 否（中下游）= 真实低迷 |
| 近 3 场是否连败 | 否（胜负交替）= 波动 | 是 = 真实崩溃 |
| 大败场地是否与本场相反 | 是（客场大败+本场主场）= 主客差异 | 否 |

大败后立即大胜强队 = 攻击力爆发 + 防守不稳，非单向崩溃；读近况时以近 3 场整体趋势为准，不以单场大败下结论。

## D. 「排名差 + 主场不败」组合的质量核查与进攻低迷

> 来源：重庆铜梁龙 2-3 北京国安（2026-05-30 中超）。积分差 12 分 + 主场不败被判"碾压"，忽视近 4 场仅 1 球的进攻低迷。存档：[20260531_case_03_chongqing_vs_beijing.md](20260531_case_03_chongqing_vs_beijing.md)。

**D1：中超「排名差 ≥10 分 + 主场近 5 场不败」不等于碾压**，必须同时核查近期进球数与不败质量。

**D2：主场不败质量分级**（记录）：

| 主场不败质量 | 判定 |
|------------|------|
| 含 2 球+ 净胜（2-0、3-1） | 高质量 |
| 多为 1 球净胜（1-0、2-1） | 中等 |
| **多为 0-0、1-1 小比分** | **低质量（防守稳但进攻存疑）** |

**D3：近期进球数**（进球数比胜负数更反映当前进攻能力；数字引用【事实表】）：

| 主队近 4 场 | 客队近 3 场 | 记录 |
|-----------|-----------|---------|
| 主队 ≥6 球 + 客队 ≤3 球 | 进攻方主队 | 偏主 |
| 均 3~5 球 | 均衡 | 无 |
| **主队 ≤2 球 + 客队 ≥6 球** | 进攻方客队 | 偏客 |
| 主队 ≤2 球 + 客队 ≤2 球 | 双方低迷 | 记录「双方进攻低迷」 |

> 原权重上限（25%/35%）与 ±5%/−10% 调整已删除。

## E. 极端动力差异（基本面层方向覆盖条件）

> 来源：天津津门虎 1-0 大连英博（2026-05-31 中超）。机械套用凯利双重极端强制反转推客队，实际保级方主胜。存档：[20260531_case_04_tianjin_vs_dalian.md](20260531_case_04_tianjin_vs_dalian.md)。

**E1：满足以下 ≥ 3 项 = 极端动力差异 → 基本面层可提出保级方方向**（同时 H-K-F 不触发，见 [feedback_kelly_signals.md](feedback_kelly_signals.md) F 节）：

> 本条是新四层中基本面层**两条方向覆盖条件之一**（另一条是 [feedback_fundamentals_weight.md](feedback_fundamentals_weight.md) B1）。
> 数据缺失的要件不算满足（排名、积分差取积分榜块；剩余轮次按积分榜已赛场次推算）。

| 条件 | 阈值 |
|------|------|
| ① 主队保级死战 | 排名 ≥ 15 且距安全区 ≤ 6 分 |
| ② 客队争冠/保级无望 | 距榜首 ≥ 12 分 或 距降级区 ≥ 10 分 |
| ③ 客队客场胜率低 | < 50% |
| ④ 剩余轮次少 | ≤ 8 轮 |

触发后信号强度为「弱」（仅基本面覆盖：只定方向、不加概率，p_最终 = p_市场）。原「保级死战动力 55% / 盘口 25%」权重已删除。

**E2：客队「无欲无求」识别**：争冠无望/保级无忧 + 客场胜率 < 50% + 有输弱队前科 → 记录「客场易轮换保守」。

**H-F-E3（假设层）：保级死战场景下临场降盘 + 主水反升 → 预测保级方不受影响**（「风控平衡、非诱上」解释）；此时 H-L-A1 / H-L-A3 不触发。

**E4：开球后的数据不可用于赛前预测**，只能在复盘时验证逻辑。

**适用/不适用速查**：常规比赛/动力均衡 → H-K-F 照常记录；**保级死战 vs 无欲无求 / 争冠决战 vs 保级队 / 德比 / 杯赛决赛（极端战意差）→ H-K-F 不触发**。

## F. 中超通用读法（所有中超场次）

- **主场优势弱于欧洲联赛**：中超主场胜率 38%~42%，排名差 ≥ 5 名不单独构成偏离
- **主场近期防守崩盘前科**（0-3、0-4 大败）→ 记录为基本面事实
- **主队近期主场小负前 3 强队**（1-2/0-1/0-2）或主场让球盘连续 2 场+ 未兑现 → 记录「让球兑现能力波动」
- 客场连败队的反弹潜力须纳入考虑（不可只看绝对客场战绩）

> 原「主场+排名差置信度上限 75」「扣 10 分 / 扣 5 分」已删除。

## 本主题检查项

- [ ] 近况崩溃的主队对阵客场低迷队？→ 记录「主场反弹」读法
- [ ] 主场反弹四条件（主场交锋不败率 ≥60% / 客队客场净负 ≥3 球前科 / 输球对手为强队 / 积分差 ≤10 分）是否逐项核对？
- [ ] 单场大败是否误判为持续崩溃？（大败后大胜 / 输强队 / 非连败 / 场地相反）
- [ ] 「排名差+主场不败」是否核查了不败质量与近期进球数？
- [ ] 极端动力差异（保级死战 vs 无欲无求，≥3 项）？→ 基本面层可提出方向（信号强度「弱」），H-K-F 不触发
- [ ] 保级死战下临场降盘+主水反升？→ 记 H-F-E3，不记 H-L-A1/A3
