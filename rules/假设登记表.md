# 假设登记表

> 假设层的**唯一台账**：所有「盘路现象 → 赛果」规则在此登记编号、预测、状态与命中率。
> 规则正文（触发条件细节）在「来源」列所指文件中；本表只记摘要。**只有「已验证」可以定方向**。
> 登记日期：除另注日期的行外，均为**阶段 2 上线日**（部署时在此填写：2026-11-12），此后的比赛才计入「后」样本。
> 复查：每周或每新增 30 场跑 `scripts/build_hypothesis_stats.py` 更新「后」样本；状态变更须人工确认后提交。
> 来源缩写：AH=reference_asian_handicap、DA=reference_dynamic_analysis、KI=reference_kelly_index、
> OU=reference_over_under、KS/SP/LV/LS/SD/FW/CSL=对应 feedback_*.md。§ 后为章/节。

## 一、统一机械定义（触发条件的唯一口径，代码 `bot/market_facts.py` 同此）

| 概念 | 定义 |
|------|------|
| 基准庄 | 本场联赛的首要分析庄，缺则按备选顺序（CLAUDE.md 步骤 1） |
| 主线 | 基准庄在该节点报价中，两侧去抽水概率最接近 50/50 的那条让球线 |
| 初盘 / 终盘 | 我方最早采到的节点 / 开球前最后一个节点 |
| 变盘 | 基准庄主线让球绝对值相邻节点变化 ≥0.25；升盘 = 让球方让得更深，降盘 = 更浅 |
| 时段 | 早期 ≥24h；中期 6~24h；临场 ≤6h；末端 ≤1.5h |
| 热门方 | 基准庄欧赔去抽水概率从初盘到终盘上升 ≥1.5 个百分点的一方；≥3 为大热 |
| 欧亚差 | 以让球方视角的让球深度：实际初盘深度 − 欧赔换算理论深度；≥+0.25「深于换算」，≤−0.25「浅于换算」，其余「欧亚一致」 |
| 水位档 | 净水位 <0.80 超低、0.80~0.87 低、0.87~0.95 中、0.95~1.05 高、>1.05 超高 |
| 单向升水 | 主线不变的连续 ≥3 个节点里上盘净水位单调上升且累计 ≥0.10 |
| 同步 | 同一时段内欧赔概率变化与亚盘变盘方向一致 |

## 二、状态门槛

| 状态 | 条件 | 权限 |
|------|------|------|
| 假设 | 登记后触发 <30 场 | 只记录 |
| 观察中 | 30~99 场 | 只记录，报告注明命中率 |
| 已验证 | ≥100 场，ROI >0，按时间前后两半 ROI 同号，剔除最大单笔后仍同号 | 可定方向 |
| 已否决 | ≥60 场且命中率 95% 区间上界 <50% | 从提示词移除 |

- 「前」样本只用于初始分级与排序，**不计入门槛**；全量历史回测（`scripts/backtest_hypotheses.py`）显示在数百场上明显为负的，可提前判否决。
- 互相矛盾的两条（如热门有难 vs 欧亚同步升盘）各自独立登记，触发条件按第一章定义互斥，谁先达标谁生效。
- 「机判」✗ = 含主观或外部不可得数据（澳门/易胜博/注码等），永远停在「假设」，除非改写触发条件。
