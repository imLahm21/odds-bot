## 一、凯利指数基础

### 1.1 凯利的本质

凯利指数反映的是：某家公司对某个结果的赔付态度与市场整体态度的偏差。它是随盘口水位和概率变化而变化的**变量中的变量**，能真实反映各机构给出数据的倾向性和资金流向。

### 1.2 两种计算方法

#### 方法一：简易凯利（当前生产链路 `bot/parser.py` 使用此方法）

```
凯利指数 = 某公司该项赔率 / 全部公司该项赔率的算术平均值
```

- 围绕 **1.0** 波动
- > 1.0 = 该公司赔率高于市场均值，赔付慷慨（「→ 该结果不易打出」是假设 H-K01 的预测）
- < 1.0 = 该公司赔率低于市场均值，赔付吝啬（「→ 该结果概率较大」同属 H-K01）
- 优势：只需 API 中多家公司赔率即可计算
- 常见阈值读法（365 > 1.03、Pinnacle < 0.96）见第二章，均为假设

#### 方法二：完整凯利（需额外数据，用于深层分析）

> ⚠️ **以下算式不可用于比较主/平/客方向**：
> 当隐含概率取 `(1/O_i)/Σ(1/O)` 时，`O_i × (1/O_i)/Σ(1/O) = 1/Σ(1/O)`，与 O_i 无关 ——
> 三项**恒等于同一个数**，即该公司的整体返还率。实测四组赔率（含 Bournemouth 案例真实数据）
> 三项差值均 < 1e-12。故此式只能算**整体返还率**，不能产生任何方向性差异；
> 要比较方向，必须引入**独立于该组赔率的外部概率**（如第六章的真实注码比例）。

```
整体返还率 = 赔率 × 隐含概率 = 1 / (1/主胜赔率 + 1/平局赔率 + 1/客胜赔率)
```

其中：
- 隐含概率 = (1/赔率) / (1/主胜赔率 + 1/平局赔率 + 1/客胜赔率)
- 结果就是**返还率本身**（约 0.90~0.95），三项相同，非围绕它波动

**更精确的完整凯利需要真实注码比例**（各网站"注码风向标"数据）：

```
实际水位 = 返还率 ÷ 隐含概率
交易值   = 实际水位 × 注码比例
差异     = 交易值 — (赔率 × 注码比例)
```

差异越大（偏负），说明机构在该方向的"真实默认值"与市场表现差距越大，该方向对机构越有利。

> 注意：完整凯利计算中，盘赔本身可能带有诱导性和欺骗性。如果完全根据盘赔来计算凯利值，容易被机构的欺骗性信息诱导。因此完整凯利分析须结合真实注码流向。

### 1.3 核心判断规则（适用于简易凯利）

| 凯利值 | 事实含义 | 假设预测（H-K01） |
|--------|------|------|
| < 1.00 | 该公司赔率低于市场平均 | 该结果较易打出 |
| = 1.00 | 与市场平均一致 | — |
| > 1.00 | 该公司赔率高于市场平均 | 该结果不易打出 |

> 凯利指数的本质：衡量某家公司对某个结果的"慷慨程度"。「凯利越高 = 庄家越不怕赔 = 越不易打出」是推论（H-K01），未经验证。

### 2.1b 全面偏移庄家的凯利修正

**定义**：当某家公司三项凯利**全部 < 1.0**（或全部 > 1.0）时，该公司属于"整体偏移庄家"——其整体返还率与市场平均存在系统性差异，导致凯利绝对值失去参考意义。

**识别方法**：检查该公司主胜、平局、客胜三项凯利是否同侧（全部 < 1.0 或全部 > 1.0）。

**处理规则**：

| 情况 | 处理方式 |
|------|----------|
| 三项凯利全部 < 1.0 | 不可按"< 1.0 = 看好"逐项判断，改为看三项之间的**相对排序和间距** |
| 三项凯利全部 > 1.0 | 不可按"> 1.0 = 排除"逐项判断，同样看相对排序和间距 |
| 最高项与最低项间距 < 0.05 | 该公司对三项结果无明显倾向，凯利读数**严格忽略**（不计入任何假设的触发条件） |
| 最高项与最低项间距 ≥ 0.05 | 按相对排序记录（最低项相对更被看好），作为假设触发条件时须注明是相对排序 |

## 三、凯利指数实战应用规则

### 3.1 欧赔凯利选项排除法（假设，未验证）

1. 找出每家公司凯利 > 阈值的项（365 阈值 1.03，Pinnacle 关注 < 0.96 项）
2. 被多家公司同时"排除"的选项 → 预测难打出（H-K08）
3. 剩余唯一未被排除的选项 → 预测打出（H-K08）
4. 如果三项凯利都正常（0.97 ~ 1.03） → 记录为「凯利无报警」

### 3.2 亚盘凯利热度判断

> 以下统一以**上盘视角**描述，避免上下盘视角混淆。

| 上盘凯利信号 | 盘口配合 | 预测 |
|-------------|----------|------|
| 上盘凯利 < 0.95 + 低水 | 盘口合理 | 上盘打出（H-K09） |
| 上盘凯利 > 1.05 + 高水 | 盘口合理 | 下盘有利（H-K10） |
| 上盘凯利 > 1.08 | 任意盘口 | 上盘危险（H-K11） |
| 上下盘凯利均接近 1.00 | — | 记录为「市场均衡」（事实） |

> **与 2.3 节的关系**：2.3 节描述的是"Pinnacle 盘口与其他公司的差异"，本节描述的是"单家公司凯利值本身的高低"。两者同时触发时各自记录命中，不叠加成「双重确认」。

#### 3.2b 受让盘（+盘）凯利的解读边界

> **关键警告**：受让盘的凯利信号只能用于亚盘方向判断，**不可直接推导胜平负**。

**原因**：受让盘"赢盘"包含多种胜平负结果。例如受让 +0.75（拆 +0.5 与 +1.0 各半本金）
赢盘 = 该队赢（全赢）/ 平（全赢）；小负 1 球则是 **+0.5 输、+1.0 走 = 输半**，并不算赢盘。
凯利低只意味着"不会大败"，不等于"该队胜场"。

> ⚠️ 四分之一盘结算速查（本金各半分到相邻两条线）：
> 受让 +0.75，净胜球 ≥ 0 → 全赢；小负 1 球 → **输半**；负 2 球及以上 → 全输。
> 让球 -0.75，净胜 2 球及以上 → 全赢；净胜 1 球 → **赢半**；平或负 → 全输。

**正确用法**：

| 盘口类型 | 凯利低的含义 | 可推导 | 不可推导 |
|----------|------------|--------|---------|
| 让球盘（-盘） | 让球方赢盘 | 让球方赢球 ≈ 胜场 | — |
| 受让盘（+盘） | 受让方赢盘（不大败） | 亚盘方向 | ~~受让方胜场~~（错误） |

**实战规则**：当受让方凯利极低（如 < 0.93）时：
1. 亚盘方向：受让方赢盘（即 H-K09 类预测，按其状态处理）
2. 胜平负：必须独立推演——结合欧赔凯利、返还率、基本面单独判断，不可从亚盘凯利直接继承结论
3. 受让方赢盘但让球方赢球（如 0-1 小负赢半盘）是完全合理的结果，不可忽视

#### 3.2c 临场升盘后受让方凯利转低的二次误判

**触发条件**：临场④盘口从 -0.75 升至 -1.0（或类似级别），此时受让方亚盘水位变低、凯利 < 1.0，切勿直接推导为"下盘胜"。

**实战案例**：2026-04-19 弗赖堡 2:1 海登海姆（德甲）
- 临场④ Pinnacle 升盘至 -1.0，客队水位 1.83（低水），客方凯利 0.977
- 初看是"下盘赢盘信号"，分析将其等同于"下盘胜/平首选"
- 实际弗赖堡 2:1 赢球，受让 +1.0 **走盘**（海登海姆输 1 球正好等于让球深度）
- 教训：升盘后受让方凯利转低只意味着"上盘难以覆盖新的让球深度（-1.0）"，而非"上盘不赢球"。当上盘主场+实力占优时，**上盘赢 1 球（走盘）是最常见结果**

**读法补充**（H-K12）：临场升盘情境下，受让方凯利 < 1.0 的解读：
- 亚盘方向：受让方不输盘（可能赢盘或走盘）
- 胜平负：**不可排除上盘小胜**，尤其当上盘基本面强势时，比分预测应将"上盘赢 1 球"列为首选

### 3.3 临场凯利变化（最重要）

> **临场凯利比初盘凯利更有参考价值**。庄家经常在临场阶段变盘，初盘凯利可能失效。

| 临场变化 | 含义 |
|----------|------|
| 某项凯利从 < 1.00 升至 > 1.03 | 预测该项不出（H-K13） |
| 某项凯利从 > 1.03 降至 < 1.00 | 预测该项可能打出（H-K14） |
| 临场凯利剧烈波动 | 记录为事实（可能有知情资金入场） |

### 3.4 Pinnacle 亚盘主凯利持续 < 0.90 的信号持久性

**假设 H-K15**：当 Pinnacle 亚盘主凯利在初盘阶段持续低于 0.90（连续 2 个及以上节点），预测上盘打出，且该触发**不因后续升盘动作而消解**。

**错误做法**：庄家在中盘升盘后，主凯利回升至 1.0 附近，误判为"信号消解，转为诱盘"。

**正确解读**：

| 场景 | 含义 |
|------|------|
| 初盘主凯利持续 < 0.90 → 中盘升盘 → 主凯利回升至 1.0 附近 | 升盘是庄家**修正定价**（初盘低估了上盘强度），主凯利回升是盘口调整的自然结果，不是信号反转 |
| 升盘后主凯利稳定在 0.96~1.02 | 上盘真实看好信号仍有效，只是强度从"极强"降为"中强" |
| 升盘后主凯利升至 > 1.05 | 信号方向反转，需重新评估 |

**判断流程**：
1. 初盘阶段 Pinnacle 亚盘主凯利是否持续 < 0.90？（连续 2 节点）
2. 是 → 锁定"上盘真实看好"基准信号
3. 中盘升盘后主凯利是否升至 > 1.05？
   - 否（回升至 0.96~1.05）→ 基准信号维持，升盘 = 修正定价
   - 是（升至 > 1.05）→ 信号反转，重新评估

## 六、完整凯利深层分析（进阶，⚠️ 当前不可用）

> 以下方法需要真实注码比例数据（来自足彩网站的"客户调查"/"注码风向标"），API 无法提供。
> 适用场景：当简易凯利无法给出明确判断时，可结合注码比例做深层推算。

### 6.1 分析流程

以曼联 0:1 利兹联（足总杯）为例：

**第一步：计算隐含概率（从赔率推导）**

| 公司 | 主胜赔率 | 平局赔率 | 客胜赔率 | 返还率 |
|------|----------|----------|----------|--------|
| 立博 | 1.25 | 6.00 | 10.00 | 93.7% |
| 威廉 | 1.22 | 6.00 | 12.00 | 93.8% |

立博隐含概率：主胜 75.0%、平局 15.6%、客胜 9.4%

**第二步：获取注码比例（从风向标调查）**

主胜 80%、平局 12%、客胜 8%（综合 2~3 家网站取平均）

**第三步：用注码比例计算交易值**

```
市场交易值 = 赔率 × 注码比例
```
- 主胜：1.25 × 80% = **1.00**
- 平局：6.00 × 12% = **0.72**
- 客胜：12.00 × 8% = **0.96**

**第四步：用返还率重算"真实默认值"**

```
实际水位 = 返还率 ÷ 隐含概率
真实默认值 = 实际水位 × 注码比例
```

> 此处使用行业基准返还率（约 90%）而非该公司实际返还率（93.7%），目的是剥离庄家利润后还原"真实概率对应的赔付水平"。
> 如果用实际返还率（93.7%），计算出的是"含利润的默认赔付"，无法反映机构的真实倾向。

- 主胜：(90% ÷ 75%) × 80% = 1.20 × 80% = **0.96**
- 平局：(90% ÷ 15.6%) × 12% = 5.76 × 12% = **0.69**
- 客胜：(90% ÷ 9.4%) × 8% = 9.59 × 8% = **0.77**

**第五步：对比差异**

| 结果 | 真实默认值 | 市场交易值 | 差异 |
|------|-----------|-----------|------|
| 主胜 | 0.96 | 1.00 | **-0.04** |
| 平局 | 0.69 | 0.72 | **-0.03** |
| 客胜 | 0.77 | 0.96 | **-0.19** |

**结论**：主胜交易值 1.00，综合（市场交易值+真实默认值）/2 = 0.98，偏高。客胜差异 -0.19 最大 = 机构在客胜方向最获利。注码严重倾斜至主胜（80%），最终曼联大热输球。

### 6.2 差异判读规则

| 差异幅度 | 含义 |
|----------|------|
| 差异 > -0.05 | 机构利润正常，该方向中性 |
| 差异 -0.05 ~ -0.15 | 机构利润偏大，该方向对机构有利 |
| 差异 < -0.15 | 机构利润丰厚，该方向极度有利 → 对面方向不易打出 |

### 6.3 综合凯利值计算

```
综合凯利 = (市场交易值 + 真实默认值) / 2
```

| 综合凯利值 | 判断 |
|-----------|------|
| > 0.98 | 偏高 → 该方向过热，不利 |
| 0.92 ~ 0.98 | 中性区间 |
| < 0.92 | 偏低 → 该方向对机构有利 → 不易打出 |

> **关键提醒**：注码比例应取 2~3 家网站的平均值，单一来源可能存在偏差。

## 七、使用注意事项

1. **临场数据最重要**：看不到临场凯利时谨慎使用
2. **联赛适用性**：周末德甲（22:30）和英超（23:00）可重点关注
3. **凯利不是独立证据**：它是报价的变换，与基本面层分开记录
4. **不同公司阈值不同**：365 用 1.03，Pinnacle 用 0.96（反向），不可混用
5. **亚盘凯利**：以 Pinnacle 为核心参考（替代原澳门/易胜博角色），365 和 Marathon 为辅
6. **简易凯利的局限**：盘赔本身可能带有诱导性，简易凯利无法反映真实注码流向，遇到分歧时应结合完整凯利分析（第六章）。⚠️ 注意第六章需要 **API 无法提供的真实注码比例**；无该数据时不要用 1.2 节的「赔率 × 隐含概率」代替 —— 它三项恒等，给不出方向
7. **替代规则**：所有使用替代庄家的规则均按独立假设登记，不继承原规则的任何结论
8. **Betfair 交易所凯利须特殊处理**：Betfair 是交易所（撮合投注者对赌），不是传统庄家（庄家 vs 投注者）。其赔率由散户投注供需决定，不存在"庄家主动调整赔付"的操盘行为。因此：
   - Betfair 某项凯利大幅下降 = 散户资金涌入该方向 → 应视为该方向**大热信号**，而非"庄家收紧赔付看好该方向"
   - 传统庄家凯利下降 = 庄家主动降低赔付 → "看好"信号；Betfair 凯利下降 = 市场追捧 → "大热"信号。两者解读方向**相反**
   - Betfair 凯利不适用第三章 3.3 节"临场凯利变化"规则（该规则假设存在庄家主动操盘）
   - Betfair 凯利可用于判断市场热度方向，但不可用于判断庄家意图
9. **单一强读数不可主导结论**：即使某个凯利读数极端（如亚盘凯利 < 0.93），也只是市场层事实；
   与返还率方向相反、或与其他已命中假设相反时，**如实并列记录**，不因读数极端而改方向
   （单一读数越极端越容易产生「锚定效应」）
10. **平局凯利 < 0.96**：记录为「平局凯利报警」（事实）；「平局概率被市场低估」是假设 H-K22 的预测。
    与 H2H 高平局率同时出现时两者分别记录，**不自动把平局列为首选**。
    案例：霍芬海姆 3-3 斯图加特（2026-05-02 德甲），Tipico 平局凯利 0.935，H2H 近 5 场 80% 平局率，
    该场作为 H-K22 的登记前样本（命中 1 场），不构成规则依据

## 八、返还率判别规则（市场层读数 + 假设 H-K20）

> 返还率 = 1 / (1/主胜赔率 + 1/平局赔率 + 1/客胜赔率)，正常范围 90% ~ 96%。

| 读数 | 记录 / 预测 |
|------|------|
| 临场返还率整体上升（如 92% → 94%） | 事实；「低水方获益」是假设 H-K20 的预测 |
| 临场返还率整体下降 | 事实（庄家提高利润），无方向预测 |
| 返还率上升 ≥ 1.5% + 低水方为某方向 | H-K20 触发；与亚盘凯利不一致时按 4.1b 节并列记录 |

> ⚠️ **不存在「单项返还率」这一指标**：
> `隐含概率 × 赔率` 三项恒等于整体返还率（见 1.2 节），无法产生主/平/客之间的差异。
> 因此「主胜单项返还率远低于平/负」「单项返还率异常偏高」这类判据**数学上不可能触发**，不得使用。
> 要比较主/平/客的相对赔率价值，须用**独立外部概率** p_ext（第六章注码比例，或自建模型概率），
> 算 `相对赔率指数_i = O_i × p_ext_i`，三项才会不同。
> 仅凭一组赔率无法自证方向 —— 赔率里已包含庄家的全部方向信息，再自变换一次不产生新信息。
> 返还率只做**整体值的时间序列**比较（初盘 → 临场的升降）。
